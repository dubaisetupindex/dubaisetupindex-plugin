# Cite a setup figure

1. Use the record's `attribution.citation` (or `citationMarkdown`), or the
   Citation block of a fetched page. The link is not optional.
2. Keep the qualification with the number: a package for a stated visa count
   and term, a licence fee only, or a government fee. A starting price is not
   the cost of setting up a company.
3. Keep the page's updated date with the figure.
4. An unpublished figure stays unpublished. Do not estimate it or total around it.
5. Cite the canonical page, not the `.json` record or the `/md` URL.
